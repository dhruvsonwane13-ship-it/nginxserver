# StreamFlix Landing Page

A responsive streaming-service-inspired front-end demo built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — styling and responsive layout
- `script.js` — poster carousel controls and demo email form interaction

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. Wait for the published URL to appear in the Pages section.

This is an independent portfolio demo and is not affiliated with Netflix. It does not stream content or collect email addresses. The hero background uses an external Unsplash image; Google Fonts are also loaded externally.
